交通費メモ（交通費申請用明細作成アプリ）
概要

* スマホ（iPhone / Android）で使う交通費申請用の明細作成Webアプリ
* 単一のHTMLファイル（`index.html`）に HTML / CSS / JavaScript を全て内包。ビルド不要、外部ライブラリ・外部通信なし
* データは各利用者のブラウザの `localStorage` に保存（サーバー通信なし）。個人情報が外部に送信されることはない

想定利用シーン

* 個人での日々の交通費記録・月次集計
* 将来的には、社内の複数人に配布して各自のスマホで利用してもらう想定
   * 配布は「ファイルを渡す」ではなく「HTTPSのURLとして公開し、各自がSafari/Chromeでアクセス→ホーム画面に追加」という形を想定
   * iOSのSafariはローカルHTMLファイルを直接Webページとして開けない（ホーム画面追加が使えない）仕様上の制約があるため、URLでの公開が前提

実装済み機能

* 入力フォーム：日付（デフォルトは今日）／出発地／到着地／往復・片道／片道料金（テンキー表示）／目的・訪問先
   * 往復選択時は片道料金の入力だけで、往復合計（片道×2）を自動計算し表示（片道料金もカッコ書きで併記）
* 入力中の下書き自動保存：フォーム入力中の内容を自動的に保持し、アプリを閉じても次回起動時に復元
* 「前回と同じ内容で追加」：直前に保存した記録の内容（日付以外）を入力欄に一括反映
* 同一日付・同一経路・同一種別（往復/片道）の記録がすでにある場合は、保存前に確認ダイアログで警告（二重登録防止）
* よく使う経路（ショートカット）：入力時にチェックを入れると経路（出発地・到着地・往復/片道・料金・目的）を保存。タップで入力欄に一括反映。長押しで削除
* 入力補助（履歴サジェスト）：出発地・到着地・目的欄は、過去入力した値が `<datalist>` の候補として表示・選択可能
* 履歴一覧：
   * 月ごとの一覧表示（ヘッダーの矢印で月を切り替え）、月合計を常時表示
   * 「全期間を表示」トグルで、月をまたいだ全記録を月見出し・月合計付きで閲覧可能
   * 出発地・到着地・目的でのキーワード検索
   * 記録をタップすると入力フォームに内容が読み込まれ、その場で編集・更新できる（インライン編集）
   * 削除はスワイプで削除ボタンを表示→確認ダイアログを経て実行（誤操作対策）
* 名前設定：ヘッダーの「名前設定」から名前を登録。一度入れれば毎回の交通費精算書に自動で表示される
* 書き出し機能：
   * 開始日・終了日を指定して対象期間を選択 → 「書き出しイメージを作成」で交通費精算書のプレビューを画面に表示
   * 精算書にはタイトル「交通費精算書」、名前・期間・合計金額、明細表（日付・経路・種別・金額・目的と合計行）を記載。名前が未設定の場合はプレビュー上で案内を表示
   * プレビュー後、以下を選択可能
      * 共有する（Web Share API。対応端末はファイルとしてメール・メッセージ等に直接共有。非対応時はテキスト共有、それも不可の場合は案内を表示）
      * CSVを保存（ダウンロード）
      * PDFで保存（アプリ内でA4のPDFファイルを生成。印刷機能は使わない。明細が多い場合は自動で改ページし、各ページに表の見出しとページ番号を付ける。iPhoneでは共有メニューから「ファイルに保存」やメール添付、非対応環境ではダウンロード）
         * 日本語は端末のフォントで描画した画像としてPDFに収めるため、外部ライブラリ不要。そのかわりPDF内の文字は選択・検索できない
      * 上記が失敗する環境向けに「CSVをコピーする」フォールバックあり（クリップボードまたは手動コピー）
   * 各操作の結果は画面下に必ずステータス表示（成功/失敗が分かるように）
* ホーム画面追加の案内：初回起動時にバナーで案内。ヘルプ（「？」ボタン）から使い方・ホーム画面への追加方法・データ保存に関する注意事項をいつでも確認可能
* ダークモード対応（端末の設定に自動追従）、セーフエリア（ノッチ・ホームインジケーター）対応

技術的な制約・注意点

* `localStorage` はブラウザ（オリジン）ごとに独立するため、同じ入口（同じブラウザ／同じホーム画面アイコン）から開き続けることが前提
* ホーム画面のアイコン削除、ブラウザのデータ削除、機種変更でlocalStorageの内容は消える（バックアップ機能は現状なし）
* Claude.ai のチャット内プレビュー（iframe/data:URL）など、一部の埋め込みブラウザではlocalStorageやダウンロード・印刷・共有系のブラウザ機能が制限され正常動作しないことがある（アプリの不具合ではない）。実機のSafari/Chrome、またはHTTPサーバー経由でのアクセスで動作確認すること
* サーバーを持たないため、複数人で使う場合もデータは共有されない（＝個人のデータが他人に見えることはないが、集計を一箇所に集める機能は現状なし）

ファイル構成

```
index.html            … アプリ本体（これ単体でも動作する）
manifest.webmanifest  … ホーム画面追加時のアプリ名・アイコン等
sw.js                 … オフライン起動用のService Worker（HTTPSまたはlocalhostでのみ有効）
apple-touch-icon.png  … iPhoneホーム画面用アイコン（180px）
icon-192.png / icon-512.png … Android等向けアイコン
README.md             … このファイル
.claude/launch.json   … ローカル動作確認用の簡易サーバー設定（開発用途のみ、配布物には不要）
```

iPhoneでの注意：ホーム画面のアイコンから開いたアプリと、Safariで開いたページとでは記録が別々に保存される。追加後は必ずアイコンから開くこと。
